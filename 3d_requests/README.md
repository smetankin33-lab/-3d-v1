# 🖨 3DPrint — Сервис заявок на 3D печать

## Быстрый старт (PyCharm)

### 1. Установите Python
Скачайте Python 3.10+ с https://python.org и установите.

### 2. Откройте проект в PyCharm
File → Open → выберите папку `3d_requests`

### 3. Создайте виртуальное окружение
В PyCharm внизу: Python Interpreter → Add Interpreter → Virtualenv

### 4. Установите зависимости
Откройте Terminal в PyCharm и выполните:
```
pip install -r requirements.txt
```

### 5. Запустите сервер
```
python app.py
```

### 6. Откройте браузер
- **Форма заявок:** http://localhost:5000
- **Отследить заявку:** http://localhost:5000/track
- **Панель администратора:** http://localhost:5000/admin

## Структура проекта

```

    ├── track.html          # Отслеживание заявки

    ├── admin_dashboard.html # Список заявок
    ├── admin_view_request.html # Просмотр заявки
```

## Функции

### Для клиентов:
- ✅ Форма с ФИО и телефоном
- ✅ Параметры детали (размеры, материал, цвет, количество)
- ✅ Загрузка фотографий (JPG, PNG, GIF, WEBP)
- ✅ Загрузка 3D моделей (STL, OBJ, FBX, 3MF, STEP)
- ✅ Уникальный номер заявки
- ✅ Отслеживание статуса (телефон маскируется)

### Для администратора:
- ✅ Защищённый вход с паролем
- ✅ Список всех заявок с фильтрацией
- ✅ Статистика (всего/новых/в работе/готово)
- ✅ Просмотр полных данных заявки
- ✅ Смена статуса заявки
- ✅ Просмотр фотографий
- ✅ Скачивание 3D файлов
- ✅ Красивая печать заявки
- ✅ Удаление заявок

### Защита данных:
- ✅ Пароли хранятся в зашифрованном виде (bcrypt)
- ✅ Телефон маскируется при публичном просмотре
- ✅ Файлы доступны только авторизованным пользователям
- ✅ Имена файлов на диске — случайные UUID (не оригинальные)
- ✅ Защита от XSS (Jinja2 автоэкранирование)
- ✅ Защита сессий (SECRET_KEY)

## Смена пароля администратора

Откройте Terminal в PyCharm:
```python
python
>>> from app import app, db, Admin
>>> from werkzeug.security import generate_password_hash
>>> with app.app_context():
...     a = Admin.query.first()
...     a.password_hash = generate_password_hash('НовыйПароль123!')
...     db.session.commit()
...     print("Пароль изменён!")
```
